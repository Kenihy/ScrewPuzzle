# 언스크류 (UNCREW)

> 풀수록, 더 깊이 얽힌다.

타인의 비밀을 알아야 살아남지만, 알고 있다는 사실을 들키면 죽는 회귀 생존 미스터리입니다. 이 폴더에는 「언스크류 에이전트 AI 프로토타입 구현 명세 v0.1」의 **P0 범위, 첫 사건 「어제의 전달 목록」(D-30)** 을 끝까지 플레이할 수 있는 웹 프로토타입이 들어 있습니다.

타이틀 → 사망 프롤로그 → D-30 회귀 → 서해린과의 첫 대화 → 연습 해체(튜토리얼) → 회장실 인사 → 멈춘 시간(기억 조사 허브) → 스크류 퍼즐 → 단서·아이템 획득 → 전달 목록 요청 → 회장 대면 3회 → 결과(4종)까지 이어집니다.

## 실행 방법

ES 모듈을 쓰므로 파일을 더블클릭(file://)하지 말고 정적 웹 서버로 엽니다. 별도 설치나 빌드는 필요 없습니다.

```bash
cd uncrew
```

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 같은 와이파이의 휴대폰에서는 `http://<PC의 IP>:8000`으로 접속할 수 있습니다. 네트워크가 없어도 플레이할 수 있고, 이때 웹 폰트 대신 시스템 글꼴로 표시됩니다.

## 조작 방법

| 화면 | 조작 |
|---|---|
| 대화 | 대사 상자를 누르면 전체 대사가 바로 표시됩니다. **다음**은 대사가 모두 표시된 뒤에만 눌립니다. **건너뛰기**는 장면의 마지막 줄까지만 넘기며 선택지를 대신 고르지 않습니다. |
| 대화(키보드) | Space: 전체 보기 · Enter 또는 →: 다음 · Esc: 창 닫기·선택 취소 |
| 선택지 | 잠긴 선택지에는 필요한 조건이 표시됩니다. 수치 변화는 고른 뒤에 상단 띠로 보여 줍니다. |
| 기억 돋보기 · 대화 리허설 | 선택지 위 아이템 줄에서 사용합니다. 리허설은 버튼을 누른 뒤 미리 볼 선택지를 고릅니다. |
| 멈춘 시간(허브) | 주제를 누르면 난이도 창이 열립니다. 집중력은 **조사 시작**을 누를 때만 줄어듭니다. |
| 퍼즐 | 나사를 눌러 집고(금색 실선 고리), 점선 고리와 중심점이 표시된 빈 구멍을 눌러 옮깁니다. 같은 나사를 다시 누르거나 Esc를 누르면 선택이 취소됩니다. 판을 지지하는 나사가 모두 빠지면 판이 떨어지고, 아래에 가려져 있던 나사와 구멍이 드러납니다. |
| 퍼즐 도구 | 되감기 · 임시 나사함 · 처음부터(집중력 추가 소모 없음) · 포기(환급 없음) |
| 노트 | 상단 문서 아이콘. 기억 단서 · 확보 증거 · 인물 탭. PC처럼 넓은 화면(가로 980px 이상)에서는 오른쪽에 항상 표시됩니다. |
| 메뉴 | 상단 왼쪽 ≡. 노트 · 설정 · 사건 처음부터 다시 · 타이틀로 |
| 테스트 패널 | 설정에서 켜거나 ` 키로 전환합니다. 기본은 숨김입니다. |

진행은 상태가 바뀔 때마다 자동 저장되며, 타이틀의 **이어하기**로 돌아올 수 있습니다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html`, `styles.css` | 화면 틀과 스타일 (모바일 세로 기준, PC는 중앙 세로 패널 + 오른쪽 노트) |
| `src/main.js` | 진입점. 콘텐츠를 검증한 뒤 게임과 UI를 연결합니다. 검증 오류가 있으면 시작하지 않고 목록을 보여 줍니다. |
| `src/core/puzzleEngine.js` | 퍼즐 엔진. 이동 가능성 · 판 제거 · undo · 임시 나사함 · 클리어/실패 판정 (순수 함수) |
| `src/core/game.js` | 게임 상태와 원자적 변경, 대화 효과 적용, 보상 지급과 중복 방지, 결과 판정 |
| `src/core/conditions.js` | 구조화된 all/any 조건 평가기 (문자열 eval 없음) |
| `src/core/save.js` | 저장·복원·스키마 검증, 깨진 저장 격리, 로컬 이벤트 로그 |
| `src/core/validate.js` | 콘텐츠 로딩 검증 (누락 · 미등록 ID · 중복 ID · 판 영역과 구멍 목록 불일치) |
| `src/core/solver.js` | 너비 우선 탐색 풀이기. 튜토리얼 힌트와 개발용 검증에만 사용 |
| `src/data/puzzles.js` | 명세 부록 A의 검증된 퍼즐 3종 원본 + 튜토리얼 보드(별도 ID) |
| `src/data/case01.js` | 첫 사건 대본 · 선택지 · 단서 · 증거 · 주제 · 결과 |
| `src/data/config.js` | 초기 수치 · 난이도 · 아이템 · 의심도 구간 |
| `src/data/expansion.js` | 전체판 확장용 세계관 데이터 (P0 실행 코드에서는 불러오지 않음) |
| `src/ui/` | UI 컨트롤러, SVG 보드 렌더러, 대체 실루엣 일러스트, 합성 효과음 |
| `tests/` | Node 내장 테스트 러너로 실행하는 자동 검증 |
| `tools/e2e-playthrough.mjs` | 실제 브라우저에서 클릭으로 끝까지 플레이하는 자동 검증 (선택 사항) |

게임 규칙(core)과 화면(ui)을 분리했으므로, Unity로 옮길 때는 `src/data`의 데이터와 `src/core`의 규칙을 그대로 C#으로 옮기면 됩니다.

## 기본값으로 정한 사항

명세에 지정되지 않은 저위험 사항은 아래처럼 정했습니다. 제목, 핵심 루프, 기본 승패 조건, 수치 표는 명세 그대로입니다.

1. **엔진과 위치**: 저장소에 이미 같은 방식(빌드 없는 HTML/JS)의 웹 프로토타입(하트볼트)이 있어 그 관례를 따랐습니다. 기존 프로토타입은 건드리지 않고 `uncrew/` 폴더에 새로 만들었습니다.
2. **인사 장면 노드**: 명세 14.2의 "허브는 회장실 입장 직후 인사 장면에서 열린다"를 구현하려고 TUTORIAL과 MEMORY_HUB 사이에 짧은 장면 `OFFICE_ENTER`를 넣었습니다. 선택지나 수치 변화는 없습니다.
3. **재도전 체크포인트**: 서해린의 첫 대화(HAERIN_OPEN)부터 다시 시작하며 프롤로그는 생략합니다. 튜토리얼은 다시 나오지만 바로 건너뛸 수 있습니다.
4. **실패 상태의 되감기**: 이동 한도에 도달한 뒤에도 되감기 도구가 있으면 직전 이동을 되돌려 계속할 수 있습니다. 클리어 후에는 쓸 수 없습니다.
5. **판 라벨과 분위기 문구**: 주제마다 판 이름과 판이 떨어질 때의 문구를 붙였습니다. 낮은 난이도에서 깊은 단서가 새지 않도록 문구에는 단서 내용을 넣지 않았습니다.
6. **의심도 구간 연출**: 관찰 대상(40) · 제거 검토(70)에 처음 들어설 때 한 번씩 짧은 장면 반응을 덧붙입니다. 수치나 선택 규칙은 바꾸지 않습니다. 70 이상인 회장실 장면에는 문 밖 보안실장 실루엣이 계속 보입니다.
7. **제거 연출**: 의심도 100에 도달하면 선택지 고유 반응 대신 공통 제거 장면(침묵 → 보안실장 호출 → 암전)을 보여 준 뒤 결과로 갑니다.
8. **리허설 방향**: 선택지 효과의 변화량 부호로 판단합니다(0~100 보정 전). 예를 들어 의심도 0에서 −5인 선택지는 "하락"으로 표시합니다.
9. **돋보기 대상 순서**: 모순 대상이 여럿이면 선택지 순서상 첫 번째를 표시하고, 다시 쓰면 다음 대상을 표시합니다.
10. **오클릭 방지**: 대사가 모두 표시된 직후 0.18초, 화면이 바뀐 직후 0.32초 동안은 입력을 무시합니다.
11. **난이도 창 기본 선택**: 남은 집중력으로 시작할 수 있는 가장 낮은 난이도를 미리 선택합니다.
12. **튜토리얼 힌트**: 풀이기로 다음 한 수를 계산해 강조만 합니다. 정답을 자동으로 실행하지 않습니다.
13. **저장 방식**: `localStorage` 키 `uncrew.save.v1` 하나에 RunState · PuzzleState · MetaState를 함께 써서 보상과 보드 상태가 따로 저장되지 않게 했습니다. 깨진 저장은 `uncrew.save.corrupt.<시각>`으로 옮겨 두고 새 게임을 안내합니다. 로컬 로그는 `uncrew.log.v1`에 최근 400건만 남기며 외부로 보내지 않습니다.
14. **좁은 화면의 보드**: 가로 400px 이하에서는 보드를 화면 폭 전체로 넓혀 인접 구멍(80 단위) 사이 간격을 44px 이상으로 맞췄습니다.
15. **그림과 소리**: 인물은 SVG 실루엣으로, 효과음은 Web Audio 합성음으로 대체했습니다. 외부 이미지·음원 파일이 없습니다. 대화 장면에는 아주 작은 저음 배경음이 있고 큰 의심 증가 때 잠시 낮아집니다.
16. **결과 화면의 플레이 시간**: 사건 시작부터 결과까지 걸린 시간을 표시합니다. 실제 플레이 시간 측정에 쓸 수 있습니다.
17. **개발용 핸들**: 브라우저 콘솔에서 `__uncrew.game`으로 상태를 볼 수 있습니다. 테스트 패널의 "해법 재생"은 개발용이며 기본 화면에는 없습니다.

## 알려진 제한

- **플레이 시간 미측정**: 전체 분기의 대사는 약 2,700자이고 한 번의 플레이에서 읽는 양은 그 60~70% 정도입니다. 퍼즐 시간을 더해도 첫 플레이는 **8~15분 정도로 추정**되어 목표(15~25분)보다 짧을 수 있습니다. 사람이 직접 플레이해 결과 화면의 시간을 기록한 뒤 분량을 조정해야 합니다.
- **실기기 미검증**: 터치 조작은 브라우저 화면 크기 에뮬레이션과 마우스 클릭으로만 확인했습니다. iOS Safari와 Android Chrome 실기기 확인이 필요합니다.
- **어려움 보드의 좁은 구멍**: 부록 지형의 구멍 m과 l은 60 단위 간격이라 360px 화면에서 약 34px로, 권장 터치 간격(44px)보다 좁습니다. 검증된 지형을 바꾸지 않으려고 그대로 두었고, 가까운 구멍을 고르는 방식으로 판정합니다.
